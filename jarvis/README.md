# Jarvis — עוזר AI מקומי ל-Galaxy S25

עוזר אישי בעברית שרץ **כולו על הטלפון**: מבין פקודות בטקסט או בקול ומבצע אותן באפליקציות (WhatsApp, שעון, ווייז, יוטיוב ועוד).
נבנה עם **Expo (React Native) + מודול Kotlin מקורי** לשירות הנגישות, ו-**llama.cpp** להרצת המודל על המכשיר.

```
אתה ──► פקודה (טקסט/קול)
          │
          ├─► נתב פקודות עברי מהיר ──(זוהה)──► פעולה אחת ─┐
          └─► מודל AI מקומי (צעד אחרי צעד, JSON בלבד) ──────┤
                                                            ▼
        ולידציה (zod) ► זיהוי איש קשר ► מדיניות אבטחה ► אישור משתמש ► ביצוע ► אימות
                                                            │
                         Intents / deep links  ◄────────────┤  (קודם כל — מהיר ואמין)
                         שירות נגישות (לחיצה/הקלדה/גלילה) ◄──┘  (רק כשאין דרך אחרת)
```

## מה שיניתי לעומת התוכנית של GPT — ולמה

התוכנית של GPT טובה בעקרונות (מנוע פעולות סגור, הרשאות בשלוש רמות, בנייה בשלבים). שיפרתי כמה דברים מהותיים:

| נושא | התוכנית המקורית | מה בניתי | למה |
|---|---|---|---|
| **מסגרת** | Kotlin + Jetpack Compose | **Expo + מודול Kotlin מקומי** (`modules/jarvis-agent`) | ביקשת Expo. הממשק והלוגיקה ב-TypeScript, והחלקים שחייבים להיות native (נגישות, Overlay, Intents) ב-Kotlin. |
| **מנוע AI** | LiteRT-LM + Gemma 4 | **llama.cpp דרך `llama.rn`** + מודלי GGUF (Gemma 3 4B כברירת מחדל) | ל-LiteRT-LM אין חיבור ל-React Native. ל-llama.rn יש config plugin ל-Expo, תמיכה ב-GPU של Snapdragon, ובעיקר **פענוח מוגבל לפי JSON Schema**: המודל *לא יכול* להחזיר JSON לא תקין. המנוע מאחורי ממשק `LlmEngine`, כך שאפשר להוסיף LiteRT-LM בהמשך בלי לגעת בסוכן. |
| **ביצוע פעולות** | ניווט ב-UI של WhatsApp דרך Accessibility (חיפוש איש קשר, פתיחת שיחה, הקלדה) | **Intent-first**: פתיחת השיחה עם הטקסט כבר מוקלד דרך deep link, ונגישות רק כדי ללחוץ "שלח" | הרבה יותר מהיר ואמין. ניווט ב-UI נשבר בכל עדכון של WhatsApp; deep link לא. אותו דבר לשעון מעורר, טיימר, חיוג, ניווט וחיפוש. |
| **הבנת פקודות** | הכל דרך המודל | **נתב פקודות עברי דטרמיניסטי** + מודל רק למה שלא זוהה | "פתח וואטסאפ" / "שלח לאמא ש…" / "טיימר 5 דקות" עובדים מיד, גם לפני שהורדת מודל, בלי סוללה ובלי טעויות של מודל קטן. |
| **עצירה ואישור** | "כפתור עצירה גלובלי" | **Overlay צף של שירות הנגישות** עם כפתור "עצור" וכרטיס אישור — מעל כל אפליקציה | כש-Jarvis פועל בתוך WhatsApp, האפליקציה שלו ברקע — כפתור בתוך האפליקציה לא נגיש. Overlay מסוג `TYPE_ACCESSIBILITY_OVERLAY` לא דורש הרשאת "הצגה מעל אפליקציות". |
| **אבטחה** | בדיקה בצד ה-AI | **שתי שכבות**: מדיניות ב-TS + `SafetyGuard.kt` ב-native | גם אם יש באג ב-JS, הקוד המקורי מסרב ללחוץ/להקליד באפליקציות בנקים, תשלומים, הגדרות מערכת ומתקין חבילות, ולא קורא שדות סיסמה. |
| **טיימרים ברקע** | — | `sleep`/`waitForIdle` מקוריים | טיימרים של JS באנדרואיד מואטים כשהאפליקציה ברקע — בדיוק כשהסוכן עובד. |

## מה כבר עובד (בקוד)

- **צ׳אט בעברית, RTL מלא** (RTL מאולץ ברמת ה-native מההפעלה הראשונה), היסטוריית שיחות, מסך הגדרות, ערכת צבעים כהה.
- **נתב פקודות מהיר**: פתיחת אפליקציות (כולל התאמה עמומה לשמות בעברית), שליחה/כתיבה של הודעות WhatsApp/SMS, פתיחת שיחה, חיוג, שעון מעורר ("תעיר אותי בשבע וחצי"), טיימר ("שים טיימר של רבע שעה"), ניווט, חיפוש בגוגל/יוטיוב, "מה יש על המסך", חזור/בית/גלילה, "תזכור שאמא זה…".
- **מודל מקומי**: הורדה עם התקדמות, טעינה (GPU עם נפילה ל-CPU), זמן תגובה וטוקנים/שנייה מתחת לכל תשובה, עבודה ללא אינטרנט.
- **סוכן רב-שלבי**: המודל מחזיר פעולה אחת בכל צעד, מקבל את התוצאה ואת המסך הנוכחי, ומתאושש משגיאות (עד 3 כישלונות או 12 צעדים).
- **שירות נגישות**: קריאת מסך כרשימה תמציתית של אלמנטים עם מספרים, לחיצה לפי מזהה/טקסט (קואורדינטות רק כגיבוי), הקלדה, גלילה, חזור/בית, המתנה עד שהמסך נרגע.
- **שלוש רמות הרשאה**: רמה 3 (שליחה, מחיקה, רכישה, אישור, פרסום — מזוהה גם לפי טקסט הכפתור) **תמיד** מבקשת אישור עם הנמען, המספר והטקסט המדויקים.
- **קול**: זיהוי דיבור בעברית (על המכשיר כשנתמך), לחיצה-לדיבור בלבד (אין האזנה ברקע), הקראת תשובות.
- **זיכרון מקומי (SQLite)**: שיחות, כינויים ("אמא" → שם/מספר), יומן משימות עם **שמות פעולות בלבד** (בלי תוכן מסך ובלי תוכן הודעות).

## התקנה על ה-S25

### דרך א׳ — בנייה בענן עם EAS (לא צריך Android Studio)

```bash
cd jarvis
npm install
npx eas-cli@latest login          # חשבון Expo חינמי
npx eas-cli@latest build -p android --profile preview
```

בסוף תקבל קישור/QR להורדת קובץ APK. פותחים אותו בטלפון ומאשרים "התקנה ממקורות לא ידועים".
לפיתוח עם רענון חי: `--profile development` ואז `npx expo start` במחשב.

### דרך ב׳ — בנייה מקומית עם כבל USB

צריך Android Studio (בשביל ה-SDK וה-NDK) ו-JDK 17+.

1. בטלפון: הגדרות ← אודות הטלפון ← פרטי תוכנה ← הקש 7 פעמים על "מספר Build". אחר כך: אפשרויות מפתחים ← **ניפוי באגים ב-USB**.
2. חבר בכבל ואשר את המחשב בטלפון. בדיקה: `adb devices`.
3. ```bash
   cd jarvis
   npm install
   npx expo run:android --device
   ```
4. לוגים בזמן אמת: `adb logcat | grep -i -E "jarvis|ReactNativeJS|llama"`.

### אחרי ההתקנה

1. **הפעלת שירות הנגישות**: באפליקציה ← הגדרות ← הרשאות ואבטחה ← "הפעל עכשיו".
   ב-Samsung, לאפליקציה שהותקנה מחוץ לחנות, האפשרות תהיה אפורה: הגדרות ← אפליקציות ← Jarvis ← ⋮ (למעלה) ← **"אפשר הגדרות מוגבלות"**, ואז חוזרים לנגישות.
2. **הורדת מודל**: הגדרות ← מודל AI ← הורד (כ-2.5GB, עדיף ב-Wi-Fi) ← טען מודל.
3. **זיהוי דיבור אופליין** (לא חובה): הגדרות Google ← שפות ← הורדת עברית לזיהוי דיבור.

## מודל האבטחה בקצרה

- המודל **לא מריץ קוד**. הוא יכול רק לבחור פעולה מתוך רשימה סגורה; הפלט מוגבל בדקדוק ועובר ולידציה נוספת.
- **אין למודל פעולה** שמשנה הגדרות או הרשאות, ו-Jarvis לא פועל בתוך מסך ההגדרות, מתקין החבילות או חנות Play.
- **בנקים ותשלומים**: אפשר *לפתוח* אותם בפקודה, אבל Jarvis לא קורא, לוחץ או מקליד בתוכם (נאכף ב-Kotlin).
- **אין הרשאות** `SEND_SMS` / `CALL_PHONE` / `WRITE_CONTACTS` / `SYSTEM_ALERT_WINDOW` (חסומות במפורש). שליחה תמיד עוברת דרך מסך האפליקציה ואישור שלך.
- **פרטיות**: אין שמירה של סיסמאות, צילומי מסך או תוכן מסך; אין גיבוי לענן (`allowBackup=false`); אינטרנט רק להורדת המודל.
- **כשל = סירוב**: אין תשובה לבקשת אישור תוך 90 שניות, או שה-Overlay לא זמין ← הפעולה מבוטלת.

## מגבלות ודברים לבדוק על המכשיר

- **לא נבנה עדיין APK.** בסביבת הפיתוח לא היה Android SDK. קוד ה-Kotlin של השירות עבר קומפילציה מול Android 15, ה-JS עבר bundle ל-Android ו-`expo prebuild` הצליח — אבל צריך לבנות ולבדוק על ה-S25 בפועל.
- **כפתור "שלח" ב-WhatsApp** מזוהה לפי `viewId=send` או תיאור "שלח"/"Send". אם WhatsApp ישנה את זה, ההודעה תישאר מוכנה בשדה ו-Jarvis יגיד לך ללחוץ בעצמך.
- **ביצועי המודל** על ה-S25 צריך למדוד (מוצג בכל תשובה). אם 4B איטי מדי, נסה Gemma 3 1B.
- **Gemma 4**: אפשר להדביק קישור ל-GGUF במסך המודל, בתנאי שגרסת llama.rn תומכת בארכיטקטורה.
- iOS לא נתמך (אין ב-iOS API שמאפשר לשלוט באפליקציות אחרות).

## השלבים הבאים (הצעה)

1. בנייה והתקנה על ה-S25 ומעבר על טבלת הבדיקות.
2. כוונון הפרומפט וזיהוי כפתורים לפי מה שרואים ב-logcat.
3. "מתכונים" לאפליקציות נפוצות (למשל יוטיוב: חיפוש ← ניגון התוצאה הראשונה) כדי לחסוך צעדי מודל.
4. מנוע LiteRT-LM כמודול native נוסף מאחורי `LlmEngine`, והשוואת ביצועים.
5. ווידג׳ט / Quick Settings tile להפעלה מהירה בקול.
