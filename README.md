# sratim3

A modern, minimalistic movie and series streaming website built with Next.js.

## Features

- Search for movies and TV series using OMDB API
- Watch movies and series with embedded iframes
- Family-friendly content filtering
- Modern, minimalistic UI design
- Responsive grid layout

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- OMDB API
